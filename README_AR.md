# بوت رولات الألوان — Neon

هذه الحزمة تحتوي على:

- بوت رولات الألوان مع رتب السيرفر الجاهزة.
- أمر `/setup_colors` لنشر إيمبد اختيار الألوان.
- أمر `/line` لإرسال صورة الخط في الشات الذي تختاره.
- صور الإيمبد والخط.
- ملف المتطلبات وطريقة التشغيل.

## مهم جداً: التوكن

التوكن غير موجود داخل الحزمة لحماية البوت من الاختراق. ضع توكن البوت في متغير البيئة باسم:

```bash
export DISCORD_TOKEN="ضع_توكن_البوت_هنا"
```

لا تضع التوكن داخل ملف `bot.py` ولا ترسله لأحد.

## التشغيل

ثبت Python 3.10 أو أحدث، ثم شغّل:

```bash
python3 -m pip install -r requirements.txt
export DISCORD_TOKEN="توكن_البوت"
python3 bot.py
```

أو:

```bash
export DISCORD_TOKEN="توكن_البوت"
./start.sh
```

في Windows PowerShell:

```powershell
py -m pip install -r requirements.txt
$env:DISCORD_TOKEN="توكن_البوت"
py bot.py
```

## تشغيل البوت على Railway

1. ارفع محتويات هذه الحزمة إلى GitHub أو ارفع ملف ZIP في مشروعك.
2. في Railway أضف متغيرًا باسم `DISCORD_TOKEN`.
3. ضع توكن البوت في قيمة المتغير من إعدادات Railway فقط.
4. سيستخدم Railway ملف `Procfile` ويشغل البوت تلقائيًا.

لا تحتاج إلى إضافة `PORT`؛ هذا بوت Discord وليس موقعًا يستقبل طلبات HTTP.

## أوامر البوت

### `/setup_colors`

ينشر رسالة اختيار الألوان مع:

- صورة `Info_2` كبانر.
- صورة `IMG_7380` كصورة صغيرة.
- خيارات الألوان بدون إيموجيات.
- خيار إزالة اللون.
- فوتر: `عمكم بلاك`.

### `/line`

يحتوي على خانة `channel`. اختر الشات المطلوب، وسيُرسل البوت صورة `Line_2` فيه.

### أوامر إضافية

- `/ping` — سرعة استجابة البوت.
- `/help` — جميع الأوامر.
- `/serverinfo` — معلومات السيرفر.
- `/userinfo` — معلومات عضو.
- `/avatar` — صورة عضو.
- `/clear` — حذف رسائل.
- `/lock` و`/unlock` — قفل وفتح الشات.
- `/slowmode` — ضبط التهدئة.
- `/announce` — إرسال إعلان.
- `/set_color` و`/remove_color` — إدارة ألوان الأعضاء.
- `/color_list` و`/roleinfo` — معلومات الألوان والرولات.
- `/suggest` — إرسال اقتراح.
- `/report` — رفع بلاغ.
- `/poll` — إنشاء تصويت.
- `/rules` — نشر القوانين.
- `/socials` — عرض روابط التواصل.
- `/setup_welcome` — تحديد شات رسائل الترحيب.

## الترحيب التلقائي

بعد تحديد الشات من خلال:

```text
/setup_welcome
```

سيُرسل البوت تلقائيًا عند دخول عضو جديد:

```text
مرحبا بك في سيرفر نيون {العضو}
عددنا الآن بفضلك {العدد}
```

مع صورة الترحيب المرفقة.

لتفعيل استقبال الأعضاء، فعّل **Server Members Intent** من:

`Discord Developer Portal > Bot > Privileged Gateway Intents`

## صلاحيات Discord المطلوبة

- `Manage Roles` حتى يستطيع إعطاء وإزالة رتب الألوان.
- `Send Messages`.
- `Attach Files`.
- عند دعوة البوت يجب تفعيل `bot` و `applications.commands`.

يجب أن تكون رتبة البوت أعلى من رتب الألوان في إعدادات السيرفر.

## ملاحظة

معرّفات رتب الألوان موجودة داخل `bot.py` ومضبوطة على السيرفر الحالي. إذا نقلت البوت إلى سيرفر آخر، غيّر معرّفات الرتب في قائمة `COLOR_ROLES`.
